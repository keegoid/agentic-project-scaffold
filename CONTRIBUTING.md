# Contributing

Issues and pull requests are welcome.

When contributing:

1. Keep the agent/playbook/ops split intact.
2. Prefer small deterministic scripts over prompt-only workflows.
3. Update `AGENTS.md`, `CLAUDE.md`, or the relevant playbook when behavior changes.
4. Add or update tests for non-trivial deterministic logic.

If you adapt the scaffold for a new domain, favor concrete examples over abstract abstractions.
